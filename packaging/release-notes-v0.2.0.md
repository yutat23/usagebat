`usage-battery` is now `usagebat`.

### What changed

- Renamed the app, executable, Go module, configuration directory, and startup registration
- Supports version reporting in tagged `go install` builds

### Downloads

- `usagebat_0.2.0_macOS_universal.zip` — Apple Silicon and Intel Mac
- `usagebat_0.2.0_windows_amd64.zip` — standard Intel/AMD Windows PCs
- `usagebat_0.2.0_windows_arm64.zip` — Windows on ARM

The binaries are not Developer ID notarized or Authenticode signed. See the README for first-launch instructions and use `SHA256SUMS.txt` to verify downloads.
